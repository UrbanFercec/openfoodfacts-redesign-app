# Open Food Facts redesign - App prototype

**https://urbanfercec.github.io/openfoodfacts-redesign-app/**

A clickable prototype of a proposed redesign. Static HTML, live product data baked in from the
Open Food Facts API - no server, no account, no camera. Not affiliated with Open Food Facts;
this is a contribution proposal under discussion.
